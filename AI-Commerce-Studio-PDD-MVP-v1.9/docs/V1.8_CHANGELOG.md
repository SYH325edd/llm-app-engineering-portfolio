# v1.8 Master Scene + Detail Composer Closure

## 1. MasterSceneLockV1

- 整套场景资产只允许一个母场景。
- 固定 sceneContext、background、surface、主光方向、色温、空间层次和固定背景元素。
- `main_01` / 明确白底目录图允许 `catalog_exempt`。
- 场景型主图与 Lifestyle/场景资产使用 `inherit_master_scene`。
- 微距、细节、规格与信息底图使用 `derived_from_master_scene`，只能裁切/虚化/低纹理化，不得换场。
- Visual Director 之后由程序再次强制应用场景锁，避免模型漂移。

## 2. Detail Composer Gate

- 必须等全部计划详情 Section 完成且 QC=PASS 后才拼接。
- 缺 Section、WARNING、FAIL、缺最终文件都会 `blocked`。
- 当前集合不完整时删除旧 `detail_full`，防止旧长图冒充当前成品。
- 拼接完成后执行 `final-detail-qc.v1`：校验 Section 数量与最终画布尺寸。
- Delivery Gate 要求最终详情长图存在且 composite QC=PASS。
