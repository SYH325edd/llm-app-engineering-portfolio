# v1.9 Prompt Specificity + Anti-Homogeneity

本版本只修复 Prompt 审计确认的四个问题。

## 1. Product Evidence Readiness
- 新增 `prompt-readiness.v1`。
- Live 模式缺 PRODUCT_TRUTH 或 confirmedFacts / IdentityLock / SurfaceAppearance 全空时直接 BLOCKED。
- Prompt 新增 `[PRODUCT EVIDENCE SUMMARY]`，商品专属事实优先于类目经验。

## 2. Asset Visual Role Contract
- 为 main_01~03、asset_01~04、detail_01~06 固定视觉角色。
- 程序在 Visual Director 后再次强制 camera / crop / occupancy / human 最低差异。
- 新增运行时镜头签名校验，阻止 `main_02=asset_03` 及 D3/D4/D5 同质化。

## 3. Detail D1-D6
- D1 认知首屏：完整商品 + Master Scene。
- D2 使用语境：同一 Master Scene 的真实使用关系。
- D3 第一证据：macro + intentional detail。
- D4 决策理由：medium close-up + 右侧信息区，不得复用 D3 微距。
- D5 结构核对：full product + deep DOF，不得微距裁切。
- D6 规格收束：完整商品缩至一侧 + 大规格安全区。

## 4. Strategy-derived Master Scene
- CommerceStrategyMap 新增 `masterSceneProposal`。
- `build_master_scene_lock()` 先读取策略提案和 CreativeReferenceProfile，最后才使用 category baseline。
- MasterScene Prompt 会记录 scene source 和 strategy rationale，便于审计。

## Validation
- 25/25 unit/integration tests pass。
- Python compileall pass。
- Demo 编译实测：main_02、asset_03、detail_03、detail_04、detail_05 镜头签名互不相同。
