# 微信公众平台上架必做项

以下操作只能在客户微信公众平台后台完成，代码包不能代替：

1. 小程序主体必须为示例教育科技有限公司。
2. 使用 AppID `wx000000000000000000`。
3. 绑定客户管理员、开发者、运营人员和体验成员微信账号。
4. 填写正式小程序名称、头像、服务介绍和实际服务范围。
5. 选择与教育辅助、作业分析和教师管理一致的服务类目，并提交平台要求的资质。
6. 完成小程序备案；备案完成后将备案号写入源码并重新构建。
7. 发布《用户隐私保护指引》，填写内容见 `WECHAT_PRIVACY_GUIDE.md`。
8. 上传体验版，使用客户真实 CloudBase 完成学生、教师、管理员、图片上传、AI、TTS、导出和失败恢复真机测试。
9. 清除测试管理员、测试教师、测试学生、测试任务和测试图片。
10. 提交审核并提供可操作的审核身份、脱敏测试数据和完整审核路径。
