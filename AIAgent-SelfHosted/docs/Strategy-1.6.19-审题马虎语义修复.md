# Strategy 1.6.19 审题马虎语义与全链路一致性

当前版本：Runtime V10.9.0 / Strategy 1.6.19。

审题马虎的唯一判定原则是“是否理解题意”，而不是“是否完整复述标准答案”。三格需要联合理解：允许合理跨格表达、对象简称、数量写在关系格、自然语言求解方向/先后步骤；不要求写标准公式、定理名称或完整 reference 文本。

明确正例：
- 正方体铁块题：条件写“正方体铁块”，关系写“先求2块正方体体积，再求长方体高”，所求写钢材高度，三格应判正确。
- 等腰三角形题：条件写“三角形”，关系中写周长57厘米、腰长23厘米并表达利用这些已知求底边，所求写底边多少厘米，三格应判正确；不得因条件格没有重复全部已知或关系格没有标准公式而判错。

下游一致性：
- `analysisStatus=ok` 表示证据可读、可判。
- 在可判状态下，学生真实漏填条件/关系/所求任一格，是普通 WRONG，不是 INCOMPLETE/UNDETERMINED。
- 只有输入证据不足、不可读或 analysisStatus 非 ok 时，才进入无法判断/不完整类。
- final summary、历史读取、前端与 TTS 必须遵循同一最终分类，不允许刷新或播报时改变结论。

本轮不处理视觉模型“漏识别图片中题目数量”的独立 coverage 问题。
