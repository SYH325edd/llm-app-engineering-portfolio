# 微信公众平台《用户隐私保护指引》正式填写表

运营主体：示例教育科技有限公司  
客服电话及投诉电话：4000000000  
代码内隐私政策版本：1.0.1  
生效日期：2026年7月26日

## 后台入口

使用客户小程序管理员账号登录微信公众平台，在小程序设置中的《用户隐私保护指引》完成填写并发布。后台声明、代码调用和小程序内隐私政策必须一致。

## 必须声明的信息类型和用途

| 代码能力 | 后台信息类型或说明 | 必须填写的实际用途 |
|---|---|---|
| `wx.chooseMedia` | 选中的照片或视频信息 | 用户主动拍摄或选择作业图片、答案图片，用于上传并进行人工智能辅助识别与批改。若后台同时识别摄像头能力，填写“用户主动拍摄作业或答案图片”。 |
| `wx.chooseMessageFile` | 选中的文件 | 教师主动选择 Excel 学生花名册，用于导入姓名、地区、班级、年级和可选学号并建立学生名单。 |
| `wx.setClipboardData` | 剪切板 | 用户主动复制导出链接、结果信息或系统生成的可复制内容。系统不读取用户剪切板中的既有内容。 |
| `wx.makePhoneCall` | 用户主动拨号说明 | 用户主动拨打示例教育科技有限公司客服电话 4000000000。系统不读取通讯录，不收集用户手机号码。 |

## 隐私授权机制

以下接口用于展示、查询和同步用户对微信《用户隐私保护指引》的同意状态，本身不是额外的信息采集类别：

- `wx.getPrivacySetting`
- `wx.openPrivacyContract`
- `<button open-type="agreePrivacyAuthorization">`
- `bindagreeprivacyauthorization`

后台隐私指引未发布、声明类别缺失或与代码不一致时，图片和文件选择等隐私接口可能无法正常调用或无法通过审核。

## 小程序内政策必须对应的业务数据

- 微信 OpenID 或内部用户编号。
- 学生、教师姓名和权限信息。
- 地区、班级、年级、花名册和可选学号。
- 作业图片、答案图片、题目和答案文字。
- 批改结果、分数、错题、知识点、马虎或难题分析。
- 任务状态、教师修改记录、导出记录、TTS 语音。
- 脱敏错误码、请求编号和安全审计记录。

## 第三方处理说明

- 火山引擎火山方舟多模态模型：处理完成题目识别和批改所需的作业图片临时地址、答案图片临时地址、题目或答案文字和批改指令。
- 火山引擎语音合成服务：处理生成语音讲解所需的批改结果讲解文本。
- 不主动向第三方模型服务提供微信 OpenID、教师权限、花名册原文件或客户模型 Key。

## 儿童个人信息

教师导入花名册前必须勾选授权确认。云端在 `teacher_privacy_consents` 集合保存：

```text
teacherId
classId
consentConfirmed
consentVersion
confirmedAt
operatorOpenId
consentBatchId
source
```

后台隐私指引、隐私政策和用户协议应同时声明可能处理不满十四周岁儿童个人信息，并提供查询、更正、删除、撤回同意和投诉电话。
