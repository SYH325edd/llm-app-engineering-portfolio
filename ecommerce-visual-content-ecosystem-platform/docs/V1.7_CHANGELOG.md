# v1.7 Prompt Quality v2.2

本轮只升级 Prompt 输入与编译链，不重写 v1.6 的 QC / Retry / Delivery / Export 架构。

## 1. SourceRoleV1

上传素材新增六种权威角色：

- PRODUCT_TRUTH
- PRODUCT_DETAIL
- PACKAGING_TRUTH
- STYLE_REFERENCE
- LAYOUT_REFERENCE
- SCENE_REFERENCE

角色写入 source asset metadata。修改角色后旧 Evidence/Profile/Plan/Prompt 全部失效，必须重新分析。

## 2. EvidenceBundleV2.1

商品事实素材新增 `surfaceAppearance[]`：appearanceClass、finish、texture、reflectance、transparency、microDetail、edgeCharacter、region/part 绑定与 confidence。

创意参考素材新增 `creativeReferenceProfile`：compositionPattern、productOccupancy、cameraPattern、backgroundGeometry、surfaceSystem、propSystem、lightDirection、lightQuality、contrastPattern、colorRelationship、depthPattern、negativeSpacePattern、visualHierarchy、copyZonePattern。

## 3. Hard Separation

只有 PRODUCT_TRUTH / PRODUCT_DETAIL / PACKAGING_TRUTH 可以形成 visualProvable 商品事实和 IdentityLock。Creative Reference 即使被上游模型误标，也会被 normalize 层阻止进入 confirmedFacts / IdentityLock.features。

## 4. PromptCompilerV2.2

Prompt 在既有结构化商业摄影执行单上新增/强化：

- CREATIVE REFERENCE PROFILE
- 实际 Surface Appearance 优先于类目通用 material cues
- Reference Role 明确显示 SourceRole
- CampaignStyleLockV1.1 从 CreativeReferenceProfile 迁移视觉方法
- 视频 referenceImages 只允许商品事实素材

原则：具体 > 冗长；商品专属视觉事实 > 通用“高级感”形容词。

## 5. Validation

新增 3 个关键测试，覆盖：

1. SourceRole 事实/创意分流及 IdentityLock 隔离。
2. PromptCompilerV2.2 确实消费 SurfaceAppearance + CreativeReferenceProfile。
3. source registry 从资产 metadata 读取权威 SourceRole。

当前总测试：19/19 PASS。
