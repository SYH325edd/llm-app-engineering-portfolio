# Stage 04 Freeze Report

Status: **FROZEN-04**

Frozen Stage: Storyboard Base
Upstream: Story Bible **FROZEN-01**, Scene Plan **FROZEN-02**, Script **FROZEN-03**
Baseline: Prompt Foundry Runtime 2.0.2 architecture + Core v1.3 Frozen

## Audit Findings

1. Parent Scene refs and Shot IDs were still copied/generated by the model although they are mechanically determined.
2. Shot refs were globally valid but not restricted to the current Scene Plan refs.
3. Dialogue speaker was not required to appear in the same Shot's `character_refs`.
4. Photography enum/duration/container constraints were not fully frozen at this Unit boundary.
5. `source_evidence` was shape-checked but not reliably anchored to the current Script Scene/Beat.
6. Unknown/downstream fields such as `director` could leak into Base Storyboard.
7. Beat coverage existed but Beat order was not enforced, allowing Storyboard to reorder narrative Beats.
8. Scene Plan continuity and first-Shot continuity had no explicit ownership mapping.
9. Runtime still contained an older `storyboard_scene.v2` path in parallel with the new Stage-owned contract.

## Changes in this freeze

- Added `runtime/stages/storyboard.py` as the sole Stage 04 contract authority.
- Model no longer owns parent Scene refs or Shot IDs.
- Unit-local Shot IDs are program-generated; merged Storyboard is globally renumbered.
- Current-Scene character/prop refs are enforced; exact duplicate refs are deterministically removed.
- Dialogue is reconstructed exactly per Beat; speaker must be visible in the same Shot.
- Core v1.3 photography maps are the only allowed shot/camera/movement enums.
- Shot evidence must be an exact quote from the current Script Scene/current Beat corpus.
- Unknown/downstream fields are rejected.
- Shot Beat sequence must preserve FROZEN-02 Beat order; Runtime never sorts semantic Shots to repair it.
- Each Scene's first-Shot `continuous_with_previous` is program-owned and mirrors FROZEN-02 Scene continuity.
- Scene-internal continuity remains model-owned; Director continuity_scope/state inheritance remains Stage 06/Core-owned.
- Removed the obsolete `storyboard_scene.v2` production path and migrated boundary tests to Stage 04 contract.
