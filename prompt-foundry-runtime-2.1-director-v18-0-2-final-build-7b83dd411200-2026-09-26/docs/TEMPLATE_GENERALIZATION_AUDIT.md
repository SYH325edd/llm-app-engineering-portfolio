# Prompt Foundry 模板化去案例硬编码验收

日期：2026-09-17

## 本轮目标

本轮只处理一件事：将 Consumption Compiler / Consumption Lint 中为具体小说案例添加的硬编码移除，改为可迁移的模板级规则。测试样本可以继续包含具体故事内容，但 `runtime/**/*.py` 生产代码不得认识具体故事实体。

## 实际修改

### `runtime/consumption_compiler.py`

- 删除具体地点 / 道具 /动作状态映射表，不再针对某一故事的柜台、窗边、食品、机器等状态做翻译。
- 状态消费改为只认通用字段类别：位置、姿态、视线、表情、头部朝向、反应、动作、说话、手持道具引用等；无法确定性翻译的自定义英文状态直接省略。
- 场景静动态分离改为通用语义类别：时间态、嗅觉信息、人物当前活动、临时变化、瞬时环境状态。
- 时间相关光线不再永久写入场景资产；若能够安全保留基础光照类型，则只保留基础光照，不保留具体时间态。
- 人物稳定资产移除依赖具体时段 / 光线的外观描述，只保留稳定身份特征。
- 阶段服装使用通用阶段标签匹配，不再写死某一个具体“第 N 天”。

### `runtime/consumption_lint.py`

- 删除具体食品、位置和动作 token 的 continuity 特判。
- 连续状态判定改为：
  1. 当前 `state_in` 中可读中文状态的语义匹配；
  2. `dependency_tags`；
  3. `held_prop_refs` / `state_in.props[*].held_by`；
  4. Story Bible 中当前道具的 canonical name / aliases；
  5. 动作自身的持续态语法。
- 跨实体状态错误提示改为通用措辞，不再识别某一具体饮品 / 道具。

## 新增模板化回归测试

`tests/runtime/test_template_generalization.py`

覆盖：

- 整个 `runtime/**/*.py` 不得出现已知故事案例实体 / 自定义字段硬编码。
- “海边书店”样本：嗅觉信息、临时人物动作、临时摆设、具体时间光线不会污染静态 Scene Asset；静态书架、材质、基础自然光和色彩仍保留。
- “仓库搬运”样本：通过当前持有道具引用 + dependency tags 识别连续动作，不依赖具体故事道具名。
- 人物资产：环境光依赖描述被去除，但稳定外貌事实保留。

## 边界

本轮没有修改时长公式、Storyboard / Director 契约、Web、Frozen Core，也没有引入新的自动翻译模型。无法确定性中文化的上游字段仍按既有规则告警或阻断，而不是在消费层猜测翻译。
