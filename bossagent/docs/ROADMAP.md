# 未来发展路线

最终方向：双端视觉招聘智能体。

1. **Visual Runtime 稳定化**：截图、OCR/文字块、目标定位、鼠标键盘、滚动、前后验证、人工接管。
2. **求职端视觉只读**：真实页面搜索、读取、岗位结构化与证据保存，不自动发送。
3. **求职端监督自动化**：匹配、队列、个性化沟通、低频受监督投递、回复同步、面试时间协商。
4. **招聘端视觉只读**：读取投递与候选人简历、匹配、人才库沉淀。
5. **招聘端监督自动化**：候选人沟通、资料追问、面试协商、招聘管道推进。
6. **双端任务编排**：跨日任务、收件箱优先级、恢复、日报、审计和人工接管。
7. **商业化**：桌面安装器、版本管理、租户隔离、授权与云端控制平面；敏感业务数据仍以本地存储为默认。

发展原则：先稳定视觉感知—动作—验证闭环，再扩大真实平台动作范围；不以绕过平台安全机制作为产品能力。
