# 安全边界

## 真实平台

- 不绕过验证码、安全验证、登录限制或平台风控。
- 不读取或导出 Cookie、Token、第三方账号密码。
- 不使用代理池、账号池或反检测机制规避限制。
- 不做高频无限滚动、无限刷新、无限群发或重复投递。
- 页面状态不明确、目标置信度不足或连续验证失败时暂停并交还人工。

## 真实动作

投递、沟通等动作必须经过 Safety Guard、Quota、对象去重、风险检查和执行后验证。涉及 Offer、录用、正式拒绝、薪资/合同承诺等重大决策保留人工确认。

## 数据

简历、候选人、聊天、截图、浏览器状态、运行日志默认保存在本地运行目录。真实 API Key 仅通过环境变量提供。发布包必须排除运行数据、登录态、数据库和浏览器 Profile。
