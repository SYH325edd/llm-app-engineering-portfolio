# 五角色串行闭环

固定顺序：

```text
总指挥 → 执行员 → 监督员 → 合验员 → 终审审计员 → 锁定
```

规则：

1. 任意时刻仅启用一个角色，不允许并行或越权。
2. 总指挥只生成结构化任务清单和验收标准。
3. 执行员只按任务清单执行并提交成果、证据和自检。
4. 监督员只做问题审查，结论为 PASS / REJECT / REWRITE。
5. 合验员按验收标准量化评分，低于 95 分或强制项失败即驳回。
6. 终审审计员采用盲审，只看最终目标、验收标准、当前成果和证据，不读取监督/合验意见。
7. 任意审核驳回都返回执行员；最多自动返工 3 次。
8. 超过返工上限进入 `HUMAN_INTERVENTION_REQUIRED`。
9. 全部通过后生成内容哈希并锁定；后续修改必须创建新任务/新版本。
10. 用户可见输出只展示最终成果、结构化日志、角色评分和驳回原因，不展示模型私有推理。

配置入口：`config/orchestration.yaml`。
