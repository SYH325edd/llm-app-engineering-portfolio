# BOSS Agent 安全边界文档

## 一、基本原则

BOSS Agent 是在用户授权浏览器环境下运行的本地招聘效率工具。系统可以帮助用户搜索岗位、筛选岗位、生成话术，并在用户授权和安全限制下执行投递与打招呼。

项目不以绕过平台限制为目标，不做验证码绕过、风控绕过、封禁对抗、账号池或代理池。

所有真实动作都必须遵循：

```text
用户主动启动
用户手动登录
用户明确授权
系统限频限量
过程可审计
异常立即停止
```

## 二、允许做的事情

系统允许实现以下能力：

```text
启动本地浏览器
打开 BOSS 登录页
等待用户手动登录
检测登录状态
读取用户当前可见页面内容
读取岗位标题、公司、薪资、地点、岗位描述等公开可见信息
生成搜索计划
执行有限搜索步骤
进行岗位匹配评分
生成拟投递清单
生成打招呼草稿
在用户授权后执行有限数量的投递
在用户授权后发送有限数量的打招呼消息
记录操作日志
生成复盘报告
```

## 三、不允许做的事情

系统不允许实现以下能力：

```text
保存第三方平台账号密码
自动破解验证码
自动绕过安全验证
绕过平台风控机制
隐藏自动化特征
伪装或规避检测
使用代理池
使用账号池
进行封号对抗
无限批量投递
无限批量打招呼
在用户未授权时执行真实动作
读取与任务无关的用户隐私页面
```

如果页面出现验证码、安全验证、登录异常、账号异常、访问受限或其他不确定状态，系统必须停止自动任务，并提示用户手动处理。

## 四、真实动作上线前的必要条件

真实投递和真实打招呼上线前，必须具备以下条件：

```text
Login Gate 已完成
SafetyGuard 已完成
ActionOrchestrator 已成为真实动作唯一入口
QuotaPolicy 已完成
AuditLog 已完成
Dry-run Apply Plan 已完成
用户确认机制已完成
任务上限已完成
每日上限已完成
动作间隔已完成
异常停止机制已完成
```

在这些条件未完成前，系统只能运行 dry-run，不得真实投递或真实发送消息。

## 五、验证码与风控处理原则

验证码、安全验证和账号异常由用户手动处理，系统不得尝试绕过。

处理规则：

```text
检测到验证码：立即停止任务
检测到安全验证：立即停止任务
检测到账号异常：立即停止任务
检测到登录失效：立即停止任务
页面状态无法判断：进入人工复核
连续失败超过阈值：停止任务
```

系统可以提示用户手动处理，但不能自动解决验证码或安全验证。

## 六、dry-run 到 real-run 的升级条件

dry-run 阶段只生成计划，不执行真实动作。

dry-run 输出包括拟投递岗位、岗位分数、推荐理由、风险原因、拟打招呼话术和预计执行数量。

从 dry-run 升级到 real-run 必须满足：用户明确点击确认、任务数量在上限内、每日额度未超限、页面状态安全、没有验证码或安全验证、ActionOrchestrator 放行、AuditLog 已记录授权。

real-run 过程中每一个真实动作前，都必须重新执行安全检查。
