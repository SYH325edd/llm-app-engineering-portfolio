# 页面职责重整

## 页面边界

- `/job`：求职助手，仅搜索岗位、评分并写入岗位池，不发送消息，不执行投递。
- `/recruit`：招聘助手，仅搜索候选人、评分并写入人才库，不发送消息，不执行投递。
- `/control`：控制中心，仅管理开关、状态、Safety Guard、Scheduler、AI Provider、数据库和 BOSS 登录态摘要。
- `/auth-center`：BOSS 登录中心，仅展示本地登录态摘要。本次重整不自动打开 BOSS，也不发起登录检查。

## 安全约束

- 控制中心不再展示搜索、Dry Apply、真实投递 Smoke Test、候选人评分或真实消息按钮。
- `POST /control/run/{target}/{action}` 保留兼容入口，但统一拒绝执行并引导至对应助手页面。
- 未修改 `schema.sql`。
- 本次验证只运行离线语法检查和测试，不触发 BOSS、不发送消息、不真实投递。
