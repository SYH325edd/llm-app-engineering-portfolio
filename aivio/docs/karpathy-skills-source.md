# Karpathy Skills Integration

This project integrates a project-specific adaptation of:

- Repository: https://github.com/multica-ai/andrej-karpathy-skills
- Original install source referenced by the repository: https://github.com/forrestchang/andrej-karpathy-skills
- Skill source file: https://github.com/multica-ai/andrej-karpathy-skills/blob/main/skills/karpathy-guidelines/SKILL.md
- Cursor rule source file: https://github.com/multica-ai/andrej-karpathy-skills/blob/main/.cursor/rules/karpathy-guidelines.mdc

Local integration points:

- `CLAUDE.md` for Claude Code style project guidance.
- `AGENTS.md` for general coding-agent guidance.
- `.cursor/rules/karpathy-guidelines.mdc` for Cursor.
- `skills/karpathy-guidelines/SKILL.md` as a reusable local skill.
- The app's console system preset now includes `Karpathy 编码`.

The local files are adapted to this project's PowerShell server plus static frontend architecture rather than copied as generic instructions.
